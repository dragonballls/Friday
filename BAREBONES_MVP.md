# MVP acceptance criteria

Friday is ready only when all are true:

- Text request creates a real coding task.
- Voice request creates the same kind of coding task.
- Agent executes actual tools in the configured workspace.
- Live feed reflects actual runtime events, not simulated progress.
- Tests and command outcomes are visible.
- Task state persists across restart/interruption.
- User can stop and resume work.
- Windows launch requires no PowerShell window.
- Default interface exposes no unrelated feature panels.
